# 镜头配置删除与长按连续运动

本次增加工作台与设备端配套功能：删除镜头型号、删除物距配置，以及长按控制连续变倍和连续聚焦。

删除按钮位于多物距标定配置区。操作前显示警告弹窗：删除物距会删除对应曲线和速度数据；删除镜头型号会删除该型号下全部物距、曲线和速度数据。用户选择“是”后才发送请求。删除要求 factory 租约且设备没有活动任务。

设备端删除使用暂存和原子索引更新。删除激活物距时清空该型号的 active_profile_id；删除激活镜头时清空 active_lens_model。两种情况下都会立即卸载运行曲线、暂停依赖曲线的自动聚焦和联动，并清空持久化速度表。非激活配置删除不影响当前运行模型。

手动连续运动按钮位于设备操作区，包括连续变倍 -/+ 和连续聚焦 -/+。按钮上方的速度滑块提供1～9档选择，默认3档；按下按钮时读取并锁定本次速度，松开后可重新调整。需先获取 operation 操作权。工作台每250 ms发送保活；松开、窗口失焦或鼠标捕获结束时发送按轴停止。设备看门狗为800 ms，断连、租约失效或保活中断后自动停止。正负号表示 raw 位置减少或增加，设备通过已验证方向映射转换为板卡方向；无法确认方向映射时拒绝运动。

连续变倍会读取设备随动状态。随动已开启且当前激活曲线有效时，工作台长按ZOOM启动与设备本地手动变倍相同的随动任务：ZOOM立即按选择档位移动，FOCUS持续追赶最新曲线目标；松开后ZOOM停止，FOCUS完成最终目标追赶后结束。随动关闭或没有活动曲线时按普通单轴连续变倍执行。连续聚焦按钮始终直接控制FOCUS。

随动任务本身会出现在设备活动任务状态中。工作台在本按钮保持按下时允许这一个由自身启动的任务继续运行，不再因活动任务状态禁用按钮。鼠标仍处于按下状态时，短暂的捕获丢失会重新捕获；只有真实松开、窗口失焦或保活失败才发送停止。

上位机 Debug/Release 和设备 `libzsFocusIR.so` 均完成编译检查。按照项目约定未新增或运行测试程序，未自动驱动镜头。删除文件、长按手感、边界停止和断连看门狗需在实际设备人工验收。
